# 🎮 ゲーミフィケーション ポモドーロタイマー

集中力を高めるポモドーロタイマーに、ゲーム要素を追加しました！  
作業時間に応じてポイントを獲得し、レベルアップを目指しましょう。

## 📌 機能一覧

- ⏱️ 25分作業 + 休憩（手動管理）
- 🧩 ポイントシステム（1セッションごとに +10pt）
- 🎉 レベルアップ機能（50pt ごとにレベルアップ）
- 📝 作業ログの記録と表示
- 🔊 サウンド付きフィードバック
- 💾 ローカルストレージでデータ保存

## 🚀 使い方

1. 「スタート」ボタンでタイマー開始
2. 作業が終わると自動でポイントが加算
3. 一定ポイントでレベルアップ！モチベーション維持に！
4. ログで過去の実績をチェック
5. 「リセット」ボタンでタイマーをリセット
